# Portofolio-Web-Sederhana

Portofolio Web Wisnu  
Project sederhana untuk mata kuliah Pemrograman Web.

## 📌 Deskripsi
Ini adalah website portofolio sederhana yang dibuat menggunakan:
- HTML & PHP
- CSS
- JavaScript

Cocok sebagai latihan dasar membuat tampilan portofolio pribadi.

## 📁 Struktur File
- `index.php` – Halaman utama website
- `style.css` – File styling utama
- `main.js` – Script JavaScript
- `assets/` – Folder berisi gambar/icon

## ▶️ Cara Menjalankan
1. **Clone repo ini** ke komputer kamu:
   ```bash
   git clone https://github.com/wisnumrt/Portofolio-Web-Sederhana.git
2. **Buka dengan XAMPP** :
   
   Letakkan folder project di  `C:\xampp\htdocs\`  
   Contoh path:  `C:\xampp\htdocs\Portofolio-Web-Sederhana`
4. **Jalankan XAMPP**, lalu buka browser dan akses:
   ```bash
   http://localhost/Portofolio-Web-Sederhana/
5. **Catatan**
   
   Pastikan XAMPP (Apache) sedang berjalan.
   
   File utama menggunakan ekstensi .php, jadi perlu server lokal untuk menampilkannya.
